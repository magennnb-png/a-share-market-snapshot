# 历史数据口径

这些 CSV 由根目录 `update_market.py` 维护，主键分别是 `date+symbol`、`date` 或 `date+code`，重复运行会覆盖同一主键而不会重复插入。

- 指数与观察指数优先使用官方/指数级日线，字段含 OHLC、涨跌幅、成交量、成交额和来源。
- 指数、观察指数/ETF 和行业会在每次运行时主动重取滚动窗口，停跑数周也会自动补齐。
- 历史市场宽度只保存实际运行时观察到的快照；免费公开源不能可靠回溯漏跑日期，因此不会用当前股票池伪造过去的涨跌家数。
- 行业主源不可用时使用“新浪当前行业成员 + 腾讯个股日线等权收益”聚合；它适合比较行业强弱和排名持续性，不应视为官方市值加权行业指数收益。
- `activity` 是当日各行业成交额的百分位（0–100），值越高表示相对活跃。
- 盘中运行时，当天记录是临时值；同日再次运行会用更新的快照覆盖，收盘后运行得到完整日值。
